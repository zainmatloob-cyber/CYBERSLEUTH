Espionage Campaign Targeting Diplomatic Entities

Researchers attribute a 2026 espionage campaign to APT29, a group also tracked as Midnight Blizzard. The actor sent spear-phishing emails impersonating Norway's Ministry of Foreign Affairs to diplomats in Brussels and Warsaw.

The lure linked to hxxp://docs-viewer[.]example[.]org/view?id=7731 which delivered a ZIP archive. Inside, a shortcut file launched PowerShell to download a second stage from 192.0.2.88. The implant, which shares code with WellMess, used DNS tunneling to reach ns1.telemetry-check[.]net.

The group exploited CVE-2023-42793 in exposed build servers and abused the System.Management.Automation namespace to run scripts in memory. Persistence was achieved through a scheduled task created with schtasks.
