# Real-world evaluation: CISA joint advisories

Test split of the second CISA set (`data/real_world/batch2/manifest.json`), code frozen at `d88d86a`. Generated by `scripts/evaluate_real_world.py --split test --final`, scored **once** with the code frozen. Documents and gold derivation: `data/real_world/` and `src/evaluation/real_world.py`.

* 8 public CISA advisories (TLP:CLEAR); ATT&CK 20.1.
* **Technique gold** = every technique ID CISA cites in the advisory, resolved to v20.1. **IOC gold** = CISA's STIX bundle for the advisory.
* Negated mappings are excluded from predictions. Parent level counts a sub-technique as its parent technique.
* Technique metrics use the 8 advisories that have an ATT&CK section; the others count for indicators only.

## 1. As published: agreement with CISA's technique list, by how it was found

"Agreement" = share of predictions that CISA also cites. A prediction CISA does not cite is not necessarily wrong (advisories do not list every behaviour), so this is a lower bound on precision, not precision.

| Found by | Predicted | Agreement (exact) | Agreement (parent) |
|---|---|---|---|
| Technique ID in text | 211 | 1.00 | 1.00 |
| Name / term only | 95 | 0.02 | 0.47 |
| Model only | 15 | 0.07 | 0.80 |
| Model only, without the cut-off (comparison) | 281 | 0.00 | 0.10 |

Model-only cut-off: **0.75** (`config/technique_mapping.json`). Model-only agreement (parent): 12 of 15, Wilson 95% interval 0.55–0.93 (treats suggestions as independent; they are not, so the real uncertainty is wider).

All methods together (micro): exact P 0.67 / R 1.00; parent P 0.79 / R 1.00. Recall here is mostly the ID matcher reading CISA's own IDs.

## 6. Limitations

* 8 advisories is a small sample; per-document numbers vary widely. The only interval given (model-only agreement) treats suggestions as independent, so it understates the uncertainty.
* The set was chosen by the project owner. Advisory types: cybercrime 1, exploitation 1, ransomware 3, red-team 1, state-sponsored 2.
* CISA's technique list is incomplete by design, so agreement understates precision and recall against it measures coverage of *CISA's* labels only.
* All are US-government joint advisories with a consistent structure; vendor reports and blogs may behave differently.
* Gold IDs are read from the same PyMuPDF text extraction the system uses; text the extractor misses is missing from both.
* IOC comparison case-folds values (URL paths included) and ignores CIDR ranges.
